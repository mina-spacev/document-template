# 표

여러 항목을 비교하거나 정보를 행과 열로 정리할 때 사용합니다.

- `thead`에는 표의 제목 행을 작성합니다.
- `tbody`에는 실제 내용을 작성합니다.
- 제목 셀은 `th`, 내용 셀은 `td`를 사용합니다.
- 본문의 구분 셀에는 `th scope="row"`를 사용합니다.

## 기본 표

행과 열은 필요한 만큼 추가하거나 삭제할 수 있습니다.

```tsx copy
<table>
  <thead>
    <tr>
      <th scope="col">구분</th>
      <th scope="col">항목 A</th>
      <th scope="col">항목 B</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">비용</th>
      <td>10만 원</td>
      <td>20만 원</td>
    </tr>
  </tbody>
</table>
```

## 열 너비 지정

기본 표는 각 열의 내용과 화면 너비에 따라 너비가 자동으로 정해집니다. 열 너비를 직접 지정하려면 `table-layout: fixed`와 `colgroup`을 함께 사용합니다.

`col`의 `width`에는 `%`와 `px` 단위를 모두 사용할 수 있습니다.

- `%`: 화면 너비에 따라 열이 함께 줄어듭니다. 각 열의 합이 100%가 되도록 작성하는 방식을 권장합니다.
- `px`: 특정 열의 기준 너비를 지정합니다. 너비를 작성하지 않은 나머지 열은 남은 공간을 나누어 사용합니다.

### % 단위

```tsx copy
<table style="table-layout: fixed;">
  <colgroup>
    <col style="width: 20%" />
    <col style="width: 40%" />
    <col style="width: 40%" />
  </colgroup>
</table>
```

### px 단위

```tsx copy
<table style="table-layout: fixed;">
  <colgroup>
    <col style="width: 120px" />
    <col />
    <col />
  </colgroup>
</table>
```

## 색상 변경

### 표 전체 색상

`table`에 아래 CSS 변수를 지정하면 아티클의 메인 색상에 맞춰 표 전체 색상을 한 번에 변경할 수 있습니다. 작성하지 않은 변수에는 기본 색상이 적용됩니다.

- `--table-header-bg`: 제목 행 배경색
- `--table-header-color`: 제목 행 글자색
- `--table-accent-bg`: `data-accent`가 있는 강조 행·열 배경색
- `--table-border-color`: 셀 구분선 색상

색상값은 `#edf4ff` 같은 HEX 코드로 직접 작성하거나 [색상 팔레트](/article-element/color-tokens)의 CSS 변수를 `var(--color-blue-50)`처럼 사용할 수 있습니다. 아래 각 예시에서 `색상 코드`와 `CSS 변수`를 선택해 비교할 수 있습니다. 서비스의 기본 색상과 일관되게 유지하려면 CSS 변수 사용을 권장합니다.

### 행·열 강조와 셀 색상

행이나 열 전체를 강조할 때는 같은 `data-accent` 속성을 사용합니다.

- `<tr data-accent>`: 행 강조
- `<col data-accent>`: 열 강조

두 방식 모두 `--table-accent-bg`에 지정한 색상을 사용합니다. 헤더처럼 셀에 별도 배경색이 있는 경우에는 셀의 배경색이 우선 적용됩니다.

그 밖의 개별 색상은 기존 [색상 팔레트](/article-element/color-tokens)의 `bg-[color]-[number]`, `text-[color]-[number]`, `border-[color]-[number]` 클래스를 `tr`, `th`, `td`에 적용해 변경할 수 있습니다.

#### 행 강조

```tsx copy
<tr data-accent>
  <th scope="row">강조 행</th>
  <td>행 전체에 강조 배경색이 적용됩니다.</td>
</tr>
```

#### 셀 테두리색

표는 셀 사이의 선이 겹쳐 보이지 않도록 기본적으로 각 셀의 오른쪽과 아래쪽에만 구분선이 있습니다. 가장 오른쪽 셀에는 오른쪽 구분선도 표시하지 않습니다.

`border-red-500`과 같은 색상 클래스는 이 기존 테두리의 색상만 변경합니다. 따라서 표의 마지막 셀에서는 아래쪽 선만 바뀐 것처럼 보일 수 있습니다. 셀 네 면에 테두리를 표시하려면 `border`와 `border-red-500`을 함께 사용합니다.

## 셀 내용 정렬

표의 내용은 기본적으로 왼쪽 정렬됩니다. 셀마다 정렬을 바꾸려면 `text-left`, `text-center`, `text-right` 클래스를 사용합니다.

### 왼쪽 정렬

```tsx copy
<td class="text-left">왼쪽 정렬</td>
```

### 가운데 정렬

```tsx copy
<td class="text-center">가운데 정렬</td>
```

`rowspan` 값에는 합칠 행의 개수를 작성합니다. 병합된 다음 행에서는 해당 셀을 다시 작성하지 않습니다. 병합된 셀은 세로 가운데 정렬됩니다.

```tsx copy
<tbody>
  <tr>
    <th scope="row" rowspan="2">
      계약
    </th>
    <td>기간</td>
  </tr>
  <tr>
    <td>방법</td>
  </tr>
</tbody>
```

## 작성 시 주의할 점

- 모든 셀은 지정된 열 너비 안에서 자동으로 줄바꿈됩니다. 첫 번째 열의 구분 항목도 셀 밖으로 겹치지 않도록 줄바꿈될 수 있습니다.
- 같은 행에서 일부 셀의 내용이 여러 줄이 되더라도 다른 셀의 내용은 세로 가운데에 정렬됩니다.
- 구분 항목은 빠르게 확인할 수 있도록 가능한 한 짧은 문구를 사용해 주세요.
- 열 너비를 직접 지정할 때는 `table-layout: fixed`와 `colgroup`을 함께 사용합니다. `%` 단위는 각 열의 합을 100%로 작성하고, `px` 단위는 작은 화면에서도 내용이 지나치게 좁아지거나 표가 넘치지 않는지 확인해 주세요.
- 표의 최상단 제목 행은 `thead`와 `th`로 작성해야 기본 강조 스타일이 적용됩니다.
- 색상을 지정하지 않은 본문 셀은 흰색 배경과 기본 글자색을 사용합니다.
- 셀 안에 문단을 넣는 경우 마지막 문단의 아래 여백은 자동으로 제거됩니다.
